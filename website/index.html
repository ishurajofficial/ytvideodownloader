Made for a focused workflow

Everything you need to save media.

YtDesk checks the available formats before you choose, then keeps download progress and your recent files close at hand.

⌕

Analyze before you download

Paste a supported video link to see its thumbnail, title, channel, duration, and detected formats. Pasting never starts a download.

▣

Choose video or audio

Pick MP4 resolutions or MP3 bitrates. Separate video and audio streams are merged through FFmpeg.

↗

Follow every download

See progress, speed, size and estimated time. Cancel a running job, then open the finished file or its folder.

◷

Keep a local history

Your recent downloads and preferences are saved on your device for convenient access.

⚙

Choose where files go

Set a download folder and decide whether to embed title and channel metadata.

◇

Private by design

Media processing runs locally. YtDesk does not request or store YouTube credentials.

Get YtDesk from the project repository

Find the setup steps, source code and current build instructions on GitHub.
